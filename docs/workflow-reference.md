# Retired workflow reference

headsign now distributes skills. Use the [local skill guide](project-local-skills.md)
and [migration guide](migration.md) for current work.

The [v0.15.4 workflow reference](https://github.com/meganemura/headsign/blob/v0.15.4/docs/workflow-reference.md)
preserves the YAML vocabulary, CLI commands, hook contracts, and state formats
of the retired runtime. Read it with that version's source and ADRs.
Those commands are historical instructions, not requirements for current skills.

[Workflow lessons](workflow-lessons.md) carries the reasoning that remains
useful when a model chooses its method directly.
