# 旧ワークフローのリファレンス

headsign はスキルを配布する形に移りました。
現在の使い方は[ローカルスキルのガイド](project-local-skills.ja.md)と[移行ガイド](migration.md)を参照してください。

[v0.15.4 のリファレンス](https://github.com/meganemura/headsign/blob/v0.15.4/docs/workflow-reference.ja.md)に、旧ランタイムの YAML、CLI コマンド、hook、状態形式を残しています。
そのバージョンのソースと ADR と合わせて読む資料です。
記載されたコマンドは、現在のスキルが要求する手順ではありません。

モデルが方法を直接選ぶ場合にも役立つ知見は、[Workflow lessons](workflow-lessons.md)にまとめています。
