# Improve a project-local skill

Read [references/procedure.md](references/procedure.md) to locate the source,
assess the evidence, and verify a revision. Choose changes by their expected
effect on the user's outcome. A useful method can stay with a reason.

Keep objectives, constraints, available gates, and authority clear. Let the
working agent choose the method. Preserve requested outcomes, explicit budgets,
required reviews and approvals, and the user's ability to stop. Use existing
task authority; ask only when missing information or authority affects the result.

Include responsibility to assess the method when feedback exposes a weakness,
and at completion. The working agent chooses useful repairs or justified
retention within remaining budget. It applies repairs to
the current work, verifies affected results, and preserves useful lessons.
Assessment must not become recursive improvement work or enlarge the task budget.

Finish after the authorized revision and appropriate verification. Report the
change, evidence, and remaining gaps. If the user requested a trial or ongoing
work, continue that authorized work; revising its skill does not complete it.
